# 作品別サイトマップ

`/sitemap.xml` は既存7ページと、公開サイト上で検証できた作品詳細を最大20件掲載する静的XML。初回は27URL。架空の更新日時は付けず、重複・管理画面・API・検索パラメータを含めない。

## 更新

```sh
npm run sitemap:check
npm run sitemap:refresh
node --test tests/*.test.mjs
git diff -- sitemap.xml
```

`sitemap:check` はローカルXMLの形式・URL・件数を確認し、通信しない。`sitemap:refresh` は本番の既存7ページを取得し、セール・VR・新作の初期HTMLに実際にある詳細リンクを順番に抽出する。作品のHTTP 200、HTML、自己参照canonical、noindexでないこと、H1、要求IDと埋め込み作品データの完全一致、カテゴリ等へ戻る内部リンクを確認してから採用する。リダイレクトは追跡しない。APIエラー・404・503・IDやcanonicalが異なる作品は除外する。

7ページの検証失敗、候補なし、正常な作品ゼロ、XML不正の場合は失敗として終了し、既存ファイルを維持する。全体の検証完了後に同一ディレクトリの一時ファイルからrenameし、途中までのXMLを公開しない。一部の詳細が失敗した場合は、それらを除外した検証済み作品だけを掲載する。

1回の更新は直列、リクエスト間隔1.2秒、1件8秒で打ち切り、詳細チェック最大30件・合計最大37リクエスト。初回は27リクエストで20作品を確認。カテゴリの取得結果を再利用し、DMM APIの一覧を余分に直接取得しない。サイトマップ配信時のAPI呼び出しはゼロ。API関数は既存12個のままで、ビルド時・アクセス時の自動更新や定期ジョブは追加しない。

掲載作品を更新するときにこのコマンドを実行し、差分・テストを確認してGitHubへ反映する。既存スナップショットが将来の配信停止まで保証するものではないため、作品の入れ替え時に再検証する。全作品の網羅や毎日の自動追加はこの実装の対象外。

## 公開後

- 本番 `/sitemap.xml` がHTTP 200、XMLで配信され、検証したファイルと一致することを確認する。
- 掲載URLのHTTP 200、作品ID、自己参照canonical、内部リンクを再確認する。
- 既存のSearch Consoleプロパティで同じ `sitemap.xml` の読み込みと検出URL数を確認。代表作品をURL検査し、Googleの選択canonicalとインデックス状況を確認する。検索掲載や順位向上は公開確認だけでは判定できない。
- 価格・画像・抽出条件・計測・GA4・年齢確認・管理認証のコードは変更しない。
